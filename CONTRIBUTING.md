# Contributing

Thanks for helping make Visual Study Mode useful to more learners.

1. Open an issue describing the problem or proposed improvement.
2. Keep pull requests focused and explain the learner benefit.
3. Do not fabricate source claims, citations, benchmark results, or interactive behavior.
4. Mark toy data as synthetic and preserve accessible labels and keyboard alternatives.
5. Test at least one ordinary concept prompt and one research-paper prompt.
6. Never commit API keys, private documents, credentials, or copyrighted full-text material.

By contributing, you agree that your contribution may be distributed under this repository's MIT license.
